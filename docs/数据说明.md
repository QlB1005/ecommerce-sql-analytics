# 数据说明



本仓库**不包含业务数据**。分析 SQL 基于导师商业项目中的电商表结构编写；结论数字来自该项目一次跑数，不随仓库分发。



## 主要用到的表



| 表名 | 用途 |

| --- | --- |

| user_master | 用户、注册时间、渠道、设备 |

| user_login_log | 登录流水，用于留存 |

| product_category | 商品分类 |

| product_detail | 商品、品牌、售价、成本 |

| order_master | 订单、支付状态、金额、时间 |

| order_detail | 订单明细、数量、是否退货 |

| payment_record | 支付方式与支付结果 |

| traffic_log | 浏览 / 流量 |

| user_behavior_event | 加购等行为事件 |

| shopping_cart | 购物车（本项目分析未作为主表） |
| ad_spend_daily | 各渠道每日广告花费与投放效果 |



## 统一口径



- 时间窗口：截止日 `2026-03-17`，往前 90 天

- 支付成功：`payment_status = 'PAID'`

- 渠道贡献：GMV + 用户运费 − 未退货货本 − 佣金 − 广告花费 − 店铺运费 − 部分退款；贡献 ROI = 渠道贡献 / 广告花费

- RFM 的 M：按销售额从高到低累计贡献切分，不是按人数前 20%

- 漏斗：浏览之后 7 日内的加购 / 下单 / 支付
